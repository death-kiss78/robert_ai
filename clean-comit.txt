Curatare istoric comituri si revenire la commit 1

git checkout --orphan clean
git add .
git commit -m "Initial clean commit"
git push origin clean
git push origin --delete main
git branch -D main
git branch -M main
git push -u origin main --force

Revenire la un comit anterior cu curatarea istoricului de comituri ulterioare

git checkout main
git reset --hard <HASH>  Exemplu:  git reset --hard a3f9c2d
git push --force origin main
